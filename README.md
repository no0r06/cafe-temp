# Zen Garden Korean Cafe Website

A beautiful, zen-themed Korean cafe website built with Next.js and Tailwind CSS.

## Features

- Complete responsive design for all devices
- 20+ menu items with category filtering
- About page with cafe story and philosophy
- Contact page with form and location
- Admin panel for managing menu items
- Korean zen-themed aesthetics with pastel green palette
- Smooth animations and transitions
- SEO optimized
